
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da forca em Python para praticar manipulação de strings, listas, seleção aleatória, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Implementar a Rodada de Adivinhação

#### Descrição
Use a lista de palavras fornecida no código inicial para escolher uma palavra secreta e implemente o loop que recebe os palpites do jogador e atualiza o progresso do jogo.

#### Requisitos
O programa completo deve:

- Selecionar aleatoriamente uma palavra da lista predefinida.
- Manter o controle das letras adivinhadas e das tentativas incorretas.
- Solicitar palpites de letras e mostrar as letras corretas nas posições correspondentes, ocultando as demais (por exemplo, `_ _ _ _`).
- Atualizar o progresso após cada palpite e limitar o número de tentativas incorretas.

### 🛠️ Encerrar e Exibir o Resultado

#### Descrição
Finalize a rodada quando o jogador adivinhar a palavra ou atingir o limite de tentativas incorretas e informe o resultado.

#### Requisitos
O programa completo deve:

- Encerrar o loop assim que todas as letras da palavra forem adivinhadas ou o limite de tentativas incorretas for atingido.
- Exibir uma mensagem de vitória quando o jogador adivinhar a palavra.
- Exibir uma mensagem de derrota e revelar a palavra secreta quando as tentativas acabarem.
